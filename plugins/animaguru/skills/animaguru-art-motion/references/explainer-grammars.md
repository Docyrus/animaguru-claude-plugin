# Explainer grammars

Choose the visual operation that explains the passage. A film can use several grammars when the explanatory job changes, keeping palette, type, audio and continuity coherent. Read only the selected cards.

| Grammar | Explanatory job |
|---|---|
| [Concept morph](explainers/concept-morph.md) | Show how one object or representation becomes another. |
| [Product/interface](explainers/product-interface.md) | Make a real product detail, feature or specification readable. |
| [Data/chart](explainers/honest-data-chart.md) | Compare reliable quantities, time and events. |
| [Luminous science](explainers/luminous-science.md) | Give an abstract system a concrete metaphor and travel across scale. |
| [Editorial evidence](explainers/editorial-evidence.md) | Inspect authentic quotations, documents, photos and maps. |
| [Whiteboard reasoning](explainers/whiteboard-reasoning.md) | Accumulate an argument as a connected spatial diagram. |
| [Storytime acting](explainers/storytime-acting.md) | Support a personal story through poses, reactions and silence. |
| [Kinetic type](explainers/kinetic-type.md) | Land a short phrase, list structure, chapter or number. |
| [Presenter explainer](explainers/presenter-explainer.md) | Let an original presenter connect evidence, diagrams and reactions. |

All nine source grammars have English adaptations. The source includes eight parameterized examples; presenter-led explanation is guidance with a reference film, not a ninth ready-to-run template. No source engine API is assumed to exist in AnimaGuru.
