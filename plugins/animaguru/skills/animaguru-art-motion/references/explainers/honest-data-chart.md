# Data and financial charts

Use for reliable numbers, time, comparisons and inflection points. Write the chart’s one takeaway before constructing it. A single number may be clearer as type. Data authenticity and sourcing are separate from visual style.

## Visual structure

Establish the scale, reveal the data, then annotate the takeaway. Use one color for the protagonist and gray for context. A zero baseline and light horizontal grid can define a bar chart. Keep units, date range and a readable source on the image. Label fictional examples in every applicable shot. Match the surrounding film’s theme or place the chart on an object within its world; avoid an unexplained white report card in a dark film.

## Motion and timing

Bars grow from zero with labels tracking their tips. A line advances by x/time rather than arc length, preserving the meaning of steep changes. Trigger event annotations when the animated head reaches that event, using the inverse easing function if necessary. Stage complex changes across roughly one second per operation as a starting point. Time final values to their spoken cues and hold long enough to read, at least about .5 s in a short example. Use tabular numerals.

## Camera and transitions

Hold the camera while data grows. Move to a specific point when the narration names it. Morph only between equivalent representations of the same data, with stable identifiers and explicit scale changes. Changing revenue bars into a stock-price line would imply a false relation. A zoom into recent data should redraw the chart rather than magnify a screenshot.

## AnimaGuru adaptation and review

Store the source data and units in production records. Bars use zero baselines; a cropped line/candlestick axis needs clear disclosure and a fair scale. Distinguish “grew to 8.7 times” from “increased by 8.7 times”: the latter means a different final value. Recompute ratios from the actual labels and match endpoints across wide/detail charts. Red/green direction conventions vary by market; state them or use blue/orange with symbols. Check negative values, decimals, long labels and portrait safe areas. Avoid bounce, perspective columns and decorative 3D that distort quantity.
