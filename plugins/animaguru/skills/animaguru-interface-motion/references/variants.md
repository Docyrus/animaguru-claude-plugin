# Interface motion variants

Choose one coherent treatment from the brief; these are visual/motion recipes, not mandatory stories. They apply to Explainer, Advertisement and General Video.

## Continuous component morph

Represent each UI state with the same semantic outer component. Evaluate size, radius and position from absolute time; use closed-form springs with explicit start states. Give incoming/outgoing content separate masks and time windows so copy cannot overlap. A stretched tab indicator can use independently timed edges while a drag derives value from the cursor position.

## Mascot in the interface

Use an original mascot and measured Pixi layout anchors. Its feet, eye target and cursor interaction follow the actual screen component geometry. Preserve real labels and show supported resulting states; a mascot does not justify inventing product features.

## Liquid-glass accents

Treat refraction/displacement as an optional bounded render-texture effect over prepared content. Keep essential UI copy sharp, describe the 2D effect accurately, and budget texture size. Do not introduce true-3D claims or flatten an entire screen through blur.

Use the bundled absolute-time helpers in `src/studies/timing.ts` where appropriate. Keep actual resources and cues in the timeline, then inspect cold seeks, full-speed motion and exported frames. The shared video skill governs interviews, generation scope and delivery.
