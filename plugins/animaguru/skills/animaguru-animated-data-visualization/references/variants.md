# Pinned annotations and sonification

Choose one coherent treatment from the brief; these are visual/motion recipes, not mandatory stories. They apply to Explainer, Advertisement and General Video.

## Data-space annotations

Store annotation anchors as actual data coordinates and project them through the same scale/camera as marks. Reserve a memory zone if a note persists after its original point leaves focus. Later data must not collide with old notes.

## Identity-preserving mark transforms

Maintain IDs as points become bars or another compatible representation. Domains, missingness, baselines and units stay explicit. If a representation changes meaning, make that change legible rather than hiding it with a morph.

## Optional sonification

Derive note timing or pitch from a documented mapping and one shared cue table. Sonification can emphasize structure but does not prove a factual claim. Test actual values and ordering against the input before adding it.

Use the bundled absolute-time helpers in `src/studies/timing.ts` where appropriate. Keep actual resources and cues in the timeline, then inspect cold seeks, full-speed motion and exported frames. The shared video skill governs interviews, generation scope and delivery.
